# optimaze landing page

A static website for the optimaze project.

The solver tool lives in [`optimaze-agent`](https://github.com/danielpuri1901/optimaze-agent).
Use that repository for the current command, supported inputs, and recorded results.

This website contains earlier marketing copy.
Its speedup and formulation-rewriting claims are not evidence of shipped features or measured results.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## Files

- `index.html` contains the page.
- `style.css` contains the styles.
- `script.js` contains browser interactions.
